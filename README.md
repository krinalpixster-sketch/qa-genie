# QA Productivity Tool (QA Genie)

An AI-powered Quality Assurance productivity suite built with Flask, Google Gemini API, ReportLab, and OpenPyXL.

## Features
- **AI Test Case Generator**: Generate functional, negative, edge case, and regression test cases.
- **AI Test Scenario Generator**: Generate realistic single-sentence test scenarios.
- **AI Bug Report Generator**: Generate structured defect reports with reproduction steps.
- **AI QA Checklist Generator**: Generate inspection checklists across functional, security, UI, and performance categories.
- **Export Capabilities**: Export generated artifacts to PDF and Excel.
- **History & Search**: View, manage, and search previously generated QA reports.

## Environment Variables
- `GEMINI_API_KEY`: Google Gemini API key from [Google AI Studio](https://aistudio.google.com/).
